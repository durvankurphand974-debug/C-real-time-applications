# How to Run

## 1. Clone the Repository

```bash
git clone <your-repository-url>
```

## 2. Open the Required Folder

Navigate to the required Unit and application folder.

Example:

```text
Unit-1/Smart-Agriculture-Sensor-Monitor/
```

## 3. Compile the Program

Using g++:

```bash
g++ Code.cpp -o program
```

## 4. Run the Program

### Windows

```bash
program
```

### Linux / macOS

```bash
./program
```

# Purpose

The purpose of this repository is to implement and understand **Object-Oriented Programming concepts in C++ through real-life applications**.

The programs provide practical experience with:

* Classes and Objects
* Encapsulation
* Inheritance
* Abstraction
* Polymorphism
* Virtual Functions
* Operator Overloading
* File Handling
* Templates
* STL
* Dynamic Memory Management
* Real-Life Problem Solving

This repository is organized unit-wise so that each application can be easily studied, executed, and maintained.
